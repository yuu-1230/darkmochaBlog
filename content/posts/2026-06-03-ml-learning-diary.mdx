機械学習の基礎を学んだ。「引き算でズレがわかる」という直感から始まって、深層学習の核心までたどり着けたのが面白かった。

学び始めたばっかりだから間違ってる内容もあるかも。

---

## 機械学習の3分類

まず全体像を整理した。

- **教師あり学習** — 正解ラベルありで学習。スパム判定・価格予測など
- **教師なし学習** — 正解なしでパターンを自力発見。顧客分類・異常検知など
- **強化学習** — 報酬を頼りに試行錯誤。ゲームAI・AlphaGoなど

本質的な違いは「何を使って正しい方向を知るか」。今回は教師あり学習の　**回帰（連続値予測）**　を深掘りした。

## 用語の整理

同じ概念に複数の名前があって最初は混乱した。

| 概念 | 機械学習 | 統計学 |
| :--- | :--- | :--- |
| モデルへの入力 | 特徴量 | 予測変数・説明変数 |
| 予測したい値 | 目的変数 | 応答変数・従属変数 |
| 予測の良さを測る尺度 | 成果指標 | — |

<Tip type="info" title="ポイント">
  分野によって呼び方が違うだけで、中身は同じ概念。機械学習寄りの文脈では「特徴量・目的変数」、統計学寄りでは「予測変数・応答変数」が多い。
</Tip>

## 損失関数

予測値と正解の「ズレ」を測る仕組み。単純に引き算するとプラスマイナスが相殺されてしまうので、2つの方法がある。

- **MSE（平均二乗誤差）** — ズレを二乗して平均。大きなズレを厳しくペナルティするが、外れ値に引きずられやすい
- **MAE（平均絶対誤差）** — ズレの絶対値を平均。外れ値に強く、単位も直感的

| | MSE | MAE |
| :--- | :--- | :--- |
| ズレの扱い | 二乗 | 絶対値 |
| 外れ値への感度 | 高い | 低い |
| 向いている場面 | 外れ値が少ないとき | 外れ値が多いとき |

---

## 勾配降下法

損失を小さくするようにパラメータ（`y = ax + b` の `a` と `b`）を調整する仕組み。損失関数をグラフにするとU字カーブになり、**ボールが坂を転がり落ちるように谷底へ近づいていく**イメージ。

「少しずつ動かす」量を決めるのが**学習率**。大きすぎると振動・発散し、小さすぎると収束が遅くなる。

<Tip type="tip" title="なぜ微分で直接解かないのか">
  パラメータが100万個あると連立方程式も100万個になり計算量が膨大すぎて現実的でない。だから「傾きを見て少しずつ近づく」アプローチをとる。
</Tip>

---

## 局所最小値問題とSGD

現実の損失関数は複雑な地形で、浅い谷（局所最小値）にはまってしまうことがある。

対策が**確率的勾配降下法（SGD）**。ランダムに選んだ少量データで勾配を計算することで、毎ステップにブレが生まれ、偶然に浅い谷を抜け出せる。谷底に近づいたら学習率を小さくして収束させる（学習率スケジューリング）。

実用上は**ミニバッチ**（32〜256件）を使うのが主流。全データ（正確・遅い）と1件（速い・不安定）の中間でバランスが良い。

## バックプロパゲーション

100万個のパラメータそれぞれを「動かして→計算して→戻す」と繰り返すのは現実的でない。

解決策が**誤差逆伝播法**。工場の生産ラインで不良品が出たとき完成品に近い工程から遡って調べるように、損失から後ろ向きに各層の勾配を計算して伝えていく。各層の勾配を再利用しながら伝えるので、1回の計算で全パラメータの勾配が求まる。

```

① ミニバッチを取り出す
② 順伝播 → 予測値を出す
③ 損失を計算する
④ 逆伝播 → 後ろから勾配を計算・伝播
⑤ 全パラメータを更新
↻ 繰り返す
```

---

## 勾配消失問題とReLU

逆伝播で層を通るたびに勾配が小さくなり、最初の層に届く頃にはほぼ0になってしまう問題。シグモイド関数は両端で傾きが0に近いので、掛け算するたびに `0.1 × 0.1 × 0.1…` と消えていく。これが**勾配消失問題**。

**ReLU** はこれを解決する活性化関数。正の領域では傾きが常に1なので `1 × 1 × 1 = 1` で勾配が消えない。

```
x > 0 のとき → そのまま x（傾き = 1）
x ≤ 0 のとき → 0（傾き = 0）
```

ただし0以下では傾きが完全に0になる（Dead ReLU問題）。対策が**Leaky ReLU**で、0以下でも `0.01x` のほんの少しの傾きを残す。

## まとめ

```
損失関数（MSE・MAE）でズレを測る
    ↓
勾配降下法でパラメータを調整
    ↓
SGD・ミニバッチで効率化＆局所最小値対策
    ↓
バックプロパゲーションで全パラメータを一括更新
    ↓
ReLU・Leaky ReLUで勾配消失を防ぐ
```

全部つながっている。次は「なぜ層を重ねると表現力が上がるのか」と「CNN・RNN・Transformer」を学ぶ予定。
